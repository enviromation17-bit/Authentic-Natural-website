# Authentic Naturals V5 — editorial video + botanical scroll experience

Run: `python3 -m http.server 8000` from this folder, then visit http://localhost:8000

- Original user video is shown uncropped with object-fit:contain. Browser autoplay rules require initial muted playback; click PLAY WITH SOUND to unmute. Playback can be paused.
- Actual brand logo is cropped from user-provided product packaging, not redesigned. Higher-resolution transparent logo file recommended.
- Ingredient photography is **illustrative artwork cropped from a generated concept storyboard**, not independently verified photographs of the actual formula. Ingredient examples (amla, kalonji, coconut, fenugreek, rosemary) MUST NOT be represented as confirmed until owner provides formula.
- Uploaded reference video demonstrates editorial motion. The site implements a sticky scroll-driven ingredient visual and responsive split hero, not a recreation of the third-party website.
- Product page and shop remain demo shopping bag with no payment backend.
- Verify real product claims, licensing of any future external imagery, and product pricing before production.
- No security audit or real-device visual QA completed.
